# 来源权威性判断指南

## 一、五层分级体系

每条来源按以下五层分级。层级不是固定标签——同一个网站在不同问题上可能处于不同层级（比如 Nature 对物理学问题是一手权威，但对中国市场分析就不是）。

### T1 一手权威

原始研究、官方文件、监管文档、一手数据。信息由产生它的机构直接发布，未经中间转述。

| 领域 | T1 示例 |
|------|--------|
| 医疗 | 随机对照试验原文、临床指南（WHO/FDA/NMPA 发布）、ClinicalTrials.gov 注册的试验 |
| 学术 | 发表在同行评议期刊上的原始实证研究、核心数据集 |
| 商业 | SEC/EDGAR 财报（iXBRL 格式）、企业官方新闻稿（从投资者关系页发布的） |
| 工程 | 官方文档（带版本号）、已通过的 RFC/Internet Standard、带 Sigstore 签名的软件包 |
| 法律 | 法律原文、法院判决书、监管机构正式通知 |

### T2 强二手

经过专业审核的二次分析。原始数据由他人产生，但分析过程经过同行评议或权威机构背书。

| 领域 | T2 示例 |
|------|--------|
| 医疗 | Cochrane 系统综述、顶刊发表的 Meta 分析 |
| 学术 | 顶级期刊的综述论文（Nature Reviews、Annual Review 系列） |
| 商业 | IFCN 认证的事实核查机构报告、多个独立媒体监测平台共识（Ad Fontes + AllSides + MBFC 一致） |
| 工程 | RFC 草案（有 working group 共识）、权威标准化组织文档 |

### T3 灰色一手

有一定可信度但需要交叉验证的来源——可能有利益冲突、未经同行评议、或来自非正式渠道。

- 预印本（arXiv、bioRxiv、medRxiv）——有价值但未经同行评议
- 知名专家的个人博客或技术文章——经验可信但观点可能有偏
- 行业分析报告（有利益冲突披露的）——数据有用但分析可能受委托方影响
- Stack Overflow 高赞回答——实践经验但可能过时

### T4 聚合转述

二手或三手信息，用于发现线索但不作为结论依据。

- 新闻媒体对研究的报道（"科学家发现..."）
- 自媒体/公众号内容
- 百科类条目（维基百科、百度百科）
- 论坛讨论（Reddit、知乎）——用于了解用户真实体验，不用于支撑事实结论

### T5 拒绝使用

直接排除，不引用：

- 论文工厂产品（大规模流水线生产的学术论文）
- 已被撤回的论文（检查 Retraction Watch 数据库）
- SEO 农场（以获取搜索排名为目的生成的内容）
- 阴谋论网站
- 明确的 AI 批量生成内容（无人审核的）

## 二、领域特异的权威信号

不同领域有不同的可信度判断信号。以下是每个领域最有区分力的指标。

### 学术领域

**可靠信号（多个交叉验证更佳）：**
- **作者可验证性**：ORCID 存在 × 机构官网可查 × Google Scholar 档案一致——三者至少两个可验证
- **DOI 可解析**：通过 Crossref 能查到完整元数据
- **期刊声誉**：是否被主要索引收录（Web of Science、Scopus）。中文期刊看是否在北大核心/CSSCI/CSCD 目录
- **归一化引用影响**：用 FWCI（Field-Weighted Citation Impact）而非裸引用数——裸引用数受领域规模影响太大
- **数据可获取**：实证研究是否提供了数据可用性声明（Data Availability Statement），数据是否实际可访问
- **方法可复现**：是否提供了代码、Dockerfile、或详细的方法描述

**不可靠信号（容易造假或误导）：**
- 期刊影响因子（JIF）——可被引用卡特尔操纵
- 作者 h-index 裸值——受职业年限和领域影响
- 单篇引用数裸值——受时间和领域影响

### 工程领域

**可靠信号：**
- **官方性**：是否来自项目/框架的官方维护者
- **版本匹配**：文档版本是否与讨论的软件版本对应
- **代码验证**：声明是否有可运行的代码佐证
- **90 天活跃贡献者数**：比 star 数更能反映项目真实活跃度（star 可以买）
- **包签名**：Sigstore/SLSA Level 2+ 签名说明供应链完整性
- **Software Heritage 存档**：超过 24 个月的项目是否有存档快照

**不可靠信号：**
- GitHub star 数——可以被批量刷
- npm/PyPI 下载数——可被 CI 循环膨胀
- "awesome-xxx" 列表收录——维护标准参差不齐

### 商业领域

**可靠信号：**
- **监管文件**：SEC EDGAR iXBRL 财报——格式受监管，造假成本极高
- **多平台共识**：多个独立的媒体偏见评级平台给出一致评价
- **利益冲突披露**：分析师是否披露了与被分析对象的利益关系
- **原创 vs 通稿**：是记者独立采写还是转发 PR 通稿

**不可靠信号：**
- Forbes Councils / 付费专栏——付费即可发表，不等于 Forbes 编辑背书
- 行业奖项——很多奖项是付费申请
- "据消息人士透露"无法验证的匿名来源

### 中文特殊信号

- **学术**：北大核心目录、CSSCI、CSCD 是基本门槛。CNKI 收录不等于高质量（收录范围很广）
- **商业**：财新、界面新闻等具有独立调查传统的媒体 vs 营销号/软文平台。注意"不发稿机制"——权威财经媒体对于无法证实的消息选择不报道，这本身是质量信号
- **工程**：InfoQ 中文站、知乎专栏等——作者身份需要逐个验证，平台本身不提供权威性保证

## 三、溯源：判断信息是原创还是转述

### 原创（一手）的指纹

- 有 Methods/Results 节，包含样本量、p 值、置信区间
- 有原创图表（不是从别处截取的）
- 描述了"我们做了什么"而不是"有人做了什么"

### 转述（二手）的指纹

- 使用"据报道""研究表明""有专家指出"等引述语
- 引用了其他来源但没有自己的原始数据
- 多篇文章使用高度相似的段落（通稿特征）

### AI 生成的指纹

- 不能单凭文本流畅度判断——AI 内容可能很流畅，人类内容也可能很流畅
- 辅助信号：多篇不同"来源"使用极其相似的句式结构和论证模式
- 关键判断：是否有可验证的外部证据支持其声明，而不是内容"看起来像不像 AI 写的"

### 溯源操作

对关键声明：

1. 找到声明中引用的原始来源
2. 检查原始来源是否真的支持了该声明（不是被断章取义）
3. 检查原始来源本身的层级（T1-T5）
4. 如果找不到原始来源，降级处理

## 四、反造假：识别被操纵的权威信号

### 高风险造假信号

以下指标造假成本低（不到 100 美元即可操纵），不能单独用于判断权威性：

| 信号 | 造假方式 | 替代方案 |
|------|---------|---------|
| GitHub star 数 | 批量购买 | 用 90 天独立贡献者数替代 |
| 期刊影响因子 | 引用卡特尔 | 用 FWCI 归一化引用替代 |
| 作者 h-index | 自引膨胀 | 用 ORCID × 机构 × Scholar 三交叉验证 |
| SEO 域名权威 | 内容农场 | 看具体内容质量而非域名指标 |
| 单篇引用数 | 自引 + 合谋引用 | 看引用者的独立性和引用意图（是支持论点还是只是背景提及） |

### 一票否决清单

命中以下任一项，推荐直接拒绝引用（T5）：

- Retraction Watch 数据库中标记为已撤回
- Cabell's 掠夺性期刊黑名单或 Beall's List 收录
- 论文工厂特征（不自然的作者组合、可疑的数据模式）
- Wikipedia 标记为 Deprecated Source

### 轨道分离

同一个平台的不同频道可能有完全不同的可信度：

- Forbes.com 编辑内容 vs Forbes Councils（付费专栏）——后者不代表 Forbes 编辑立场
- Bloomberg 新闻采编 vs Bloomberg 赞助内容
- CSDN 原创技术文章 vs CSDN 搬运/翻译内容
- 知乎专业回答 vs 知乎营销号

不要给整个域名一个权威等级——看具体频道和作者。

## 五、独立性判断：多少个来源算"独立印证"

### 核心原则

两条信息来自"不同的 URL"不等于它们是独立的。以下任何一种关系成立，两条信息就不算独立来源：

- **直接引用**：A 明确引用了 B
- **文本高度重叠**：大段文字相似（超过 50 个连续字符完全相同，或段落级别的意思重复）
- **同一通稿**：两篇文章可追溯到同一条 PR 通稿
- **作者重叠**：多篇"不同"论文的作者团队大部分相同
- **机构重叠**：来自同一机构的不同发言人说同一件事
- **共同上游来源**：两篇文章引用了大量相同的参考文献（说明它们可能都在转述第三方）

### 独立来源计数方法

1. 列出所有支持某结论的来源
2. 检查上述 6 种关系，合并不独立的来源
3. 合并后剩下的组数 = 真正的独立来源数

**报告中使用"N 个独立来源支持"时，N 是合并后的数字，不是原始来源数。**

### 对"充分印证"的参考标准

| 独立来源数 | 含义 |
|-----------|------|
| 3+ 个独立高质量来源一致 | 证据确定性可评为"高" |
| 2 个独立来源或 1 个顶级来源 | 证据确定性"中" |
| 1 个普通来源 | 证据确定性"低"，关键结论需标注 |
| 0 个可验证来源 | 证据确定性"极低"，不能用于支撑行动建议 |
