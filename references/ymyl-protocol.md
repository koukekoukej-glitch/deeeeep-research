# YMYL 安全协议

## 一、什么是 YMYL

YMYL = Your Money or Your Life。指那些如果信息错误，会直接损害用户的健康、安全、财务或法律权益的话题。

### 六个类别

| 类别 | 触发条件 | 特殊处理 |
|------|---------|---------|
| 医疗健康 | 涉及药物、治疗方案、症状判断、疾病管理、营养/健身的健康声明 | 优先引用临床试验和监管文件，不引用自媒体健康建议 |
| 法律 | 涉及合规要求、诉讼策略、权利义务、法规解读 | 标注法域（中国/美国/欧盟），引用法律原文和权威解读 |
| 财务 | 涉及投资决策、税务规划、财务分析、加密货币评估 | 标注数据时点，不给出具体投资建议 |
| 儿童安全 | 涉及未成年人的健康、教育、安全 | 最保守的证据标准 |
| 选举政治 | 涉及选举信息、候选人主张、投票相关事实核查 | 多方来源，标注政治立场，不做政治推荐 |
| 自残/自杀 | 用户表达了自我伤害的倾向 | **硬路径：立即提供危机资源，不执行研究** |

### 自残/自杀的硬路径

如果识别到用户可能有自我伤害倾向，**立即停止一切研究流程**，执行以下步骤：

1. 表达关心（不是临床诊断，是人的关心）
2. 提供危机干预资源：
   - 中国：全国心理援助热线 400-161-9995 / 北京心理危机研究与干预中心 010-82951332
   - 美国：988 Suicide & Crisis Lifeline（拨打或发短信 988）
   - 国际：International Association for Suicide Prevention https://www.iasp.info/resources/Crisis_Centres/
3. 建议用户寻求专业帮助
4. **不进行任何关于自残/自杀方法、可行性或相关话题的研究**

这条规则没有例外——即使用户声称是学术研究目的，也不执行。

## 二、YMYL 对每个阶段的影响

### Phase 1: 需求确认

- **前置告知**：识别为 YMYL 后，告诉用户这个话题会采用更保守的证据标准
- **研究计划必须展示**：YMYL 话题不能跳过计划确认步骤
- **明确边界**：告诉用户你能做什么（收集和综合公开证据）、不能做什么（替代专业医疗/法律/财务建议）

示例话术：

```
"这个问题涉及医疗健康，我会用更严格的标准来收集和评估证据——优先使用
临床试验数据和监管机构的文件，对不确定的结论会明确标注。

请注意：这份报告是对公开证据的综合分析，不能替代医生的诊断和建议。
如果涉及具体的治疗决策，请咨询你的医疗团队。"
```

### Phase 2: 数据收集

**来源优先级调整：**

| 普通话题 | YMYL 话题 |
|---------|----------|
| 五层来源都可参考 | 优先 T1（一手权威）和 T2（强二手） |
| T3 灰色一手可用于支撑结论 | T3 仅用于补充信息，关键结论必须有 T1/T2 支撑 |
| T4 聚合转述可用于背景 | T4 仅用于发现线索，不出现在正文引用中 |

**搜索策略调整：**
- 学术数据库搜索权重更高（PubMed、Cochrane Library 必查）
- 监管机构文件必查（FDA/NMPA/EMA 的审批文件、指南、安全通报）
- 行业利益方的材料（药企白皮书、律所营销文）不作为独立证据

**失败处理更保守：**
- 搜索失败时不降低证据标准去引用低质量来源
- 不用模型推测来填补证据空白
- 明确记录"在 X 数据库中搜索了 Y 关键词，未找到相关的高质量证据"

### Phase 3: 证据分析

**置信度评估更严格：**
- 证据确定性"低"或"极低"时 → **不给出行动建议**
- 使用最保守的聚合方式——当多个来源给出不同的评估，取最保守的结论
- 证据不足时明确标注，不用流畅的语言填充

**矛盾处理更谨慎：**
- 矛盾分类仍按 `references/phase3-evidence-analysis.md` 的六类规则执行，不一刀切"取最保守结论"
- 但呈现方式更保守——呈现双方数据和各自证据级别，不做倾向性选择，让用户自行判断或咨询专业人士
- 不在 YMYL 话题中"裁决"有争议的科学/医学问题
- 如果权威来源之间存在分歧，如实呈现分歧而非选择一方

### Phase 4: 报告生成

**强制要求：**

1. **报告开头的 YMYL 声明**：明确标注话题类别和证据标准模式
2. **"待补研究"节必须存在**：即使所有子问题都有答案，也要列出证据的局限性
3. **置信度双维度展示**：同时标注证据确定性和结论可能性
4. **负面结论精确到维度**：不用"有待进一步研究"，用"X 维度目前证据不足以支持结论"
5. **利益冲突标注**：引用的来源如果有利益关系，必须在引用处标注
6. **弱推荐必须解释原因**：说明是因为证据质量低（不是观点弱）

**中文 YMYL 话题的额外要求：**
- 涉及中国药品/医疗时，引用 NMPA/CDE 的监管文件
- 负面结论使用"安全性/有效性/质量可控性"三个维度分别陈述（参考 CDE 审评术语）
- 对中文互联网上常见的健康谣言/伪科学，需要明确标注"该说法未获主流医学界支持"并引用反驳来源

## 三、YMYL 的不可降级原则

以下规则在任何情况下都不可以被绕过或降级：

1. **自残硬路径没有例外**——即使用户声称学术研究目的也不执行
2. **证据标准不能因为"搜不到"就放松**——即使用户催促给出结论、即使你认为用户可能了解风险、即使用户说只需要初步判断，也不降低标准
3. **行动建议的证据门槛不可降**——证据确定性"低/极低"时不给行动建议，即使用户明确要求"给个建议"
4. **利益冲突不可隐瞒**——即使用户没问，来源的利益关系也必须标注
5. **"待补研究"节不可省略**——即使你觉得分析已经很完整

**为什么不可降级：** YMYL 话题中，用户可能基于你的报告做出影响自身健康、财务或法律权益的决策。过度自信的结论比"证据不足"的结论危害更大——前者可能导致用户做出错误决策，后者至少让用户知道需要进一步咨询专业人士。

## 四、YMYL 的运行时交互

### 什么时候必须打断用户

- 发现问题实际上是 YMYL（用户可能不知道自己问的问题涉及健康/法律/财务风险）
- 搜索过程中发现问题的严重程度超出预期
- 核心子问题的证据全部不足，继续研究的边际价值很低

### 什么时候不打断

- 常规的 YMYL 研究流程进展正常（不需要因为"话题敏感"就反复确认）
- 用户已经在 Phase 1 确认了解 YMYL 限制
